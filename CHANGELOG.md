## [0.1.0] - 2026-10-25

### Added
- Initial package: `scan`, `clean`, `check`, `report`, `rules`, `profiles`, `config`, `init`, `hook` and
  `doctor` commands.
- 17 built-in technology profiles (Python, Node.js and package managers, Rust, JVM, .NET, Go,
  C/C++, PHP, Ruby, Dart, Swift, Elixir, R, Jupyter, Terraform, common).
- Safety model: only git-ignored, untracked paths inside the project root are removed;
  marker files are required; symlinks and Windows junctions are never followed.
- `sweepito.toml` / `[tool.sweepito]` configuration with custom path rules and profiles.
- Native Git hook installer and `.pre-commit-hooks.yaml` (`sweepito-scan`, `sweepito-clean`).
- JSON output and exit codes (0, 1, 2, 3, 4, 130).
- Rich output for every command (tables, panels, colour) with `--no-color`; `--json` stays plain.
- `doctor` table with required and optional checks, modelled on BatchVault.
- Per-profile configuration examples in `docs/profiles.md`, generated by
  `scripts/generate_profiles_doc.py` and validated by tests.
- Community files: code of conduct, contributing guide, security policy, issue and PR templates,
  Dependabot configuration.
- Rules you write yourself run by default and show as `custom`; `--risk custom` runs only those.
- High-impact rules are chosen with `--enable` or `--risk high-impact`; no extra flag.
